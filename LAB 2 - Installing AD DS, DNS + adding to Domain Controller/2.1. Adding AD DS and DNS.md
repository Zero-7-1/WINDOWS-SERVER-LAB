# Creating a Forrest

-

## Step 1: Click on 'Add Roles and Features'

Here we will get few suggestion to check for and most important is configuration of static IP

![Adding Roles and Features](Screenshot%202026-06-29%20122348.png)
To configure static IP inside Oracle we need to follow these:

- Open Network Connections in Control Panel, run > ncpa.cpl

- Select the 2 network adapter (That we slected as Internal Network in Oracle VirtualBox) and go to its properties. Click on IPVP4 and go to its properties. Switch the toggles from "Obtain automatically" to manual configurations. Use **192.168.10.10 for IP address**, **255.255.255.0 for Subnet mask** and **127.0.0.1 for Preferred DNS server**.

![ncpa.cpl Configuring Static IP](./Images/configStaticIP.png)

## Step 2: Installation Type and server selection

Here are 2 Options

- Role based or Feature based installation: For now I will go with this type

- Remote Desktop Services Installation

After this list of server with assigned IP will show to select, Click on Next

## Step 3: Selecting roles to install

Here I need to add the required roles to setup in the server

- Active Directory Domain Services

- DNS Server

Rest I can go with by default and clicked Next to install

![Installation Began](./Screenshot%202026-06-29%20124033.png)

## Step 4: Promoting to Domain Controller

After installation there will be notification on the flag icon that feature installations are complete. Along with this there wil be an option to promote this server to domain controller. Clicked on it. Now we will create forest inside it.

![Promoting to Domain Controller](./Screenshot%202026-06-29%20131440.png)

## Step 5: Deployment Operations

There are 3 deployment operations

1. Add a domain controller to an existing domain
2. Add a new domain to an existing domain
3. Add a new forest

I do not have a exiting domain so will go with adding a new forest. I take a name as company.com
![Forest creation](./Screenshot%202026-06-29%20131728.png)

After creating it will show domain controller options, keep those as it is and set a DSRM password. The ***Directory Services Restore Mode*** used only when the Domain Controller is booted into Directory Services Restore Mode for maintenance or disaster recovery.

Also leave next DNS Options as it is for current lab

![Domain Controller Options](./Screenshot%202026-06-29%20131816.png)
![DNS Options](./Screenshot%202026-06-29%20131920.png)

After these, I can see my created forrest name as ***NetBIOS domain name***. DNS domain name is the full internet style name, while the NetBIOS domain is the short windows name. It is auto suggested by windows based on domain naming

## Step 6: Path, Review and Installation

- The default database path for ***AD DS is C:\Windows\NTDS***. So the main file is stored inside NTDS folder of C drive by default.

- After this it will review window and a pre-requisite check will begin. There will be few warnings but in the end it gets completed succesfully. Now click install to begin installation.

![AD DS Database Path](./Screenshot%202026-06-29%20132427.png)

## Step 7: Reboot and computer is now logged in to forest profile

After all steps now system will ask to reboot. After few mins it logs to forest. Same server password here will work.

![Forest Login](./Screenshot%202026-06-29%20133017.png)
