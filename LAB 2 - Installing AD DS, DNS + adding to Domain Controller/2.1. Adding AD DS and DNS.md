# Creating a Forrest

## Step 1: Click on 'Add Roles and Features'

Here we will get few suggestion to check for and most important is configuration of static IP
![Adding Roles and Features](Screenshot%202026-06-29%20122348.png)
To configure static IP inside Oracle Virtual Box we need to follow these:

- Open Network Connections in Control Panel, run > ncpa.cpl

- Select the active network adapter and go to its properties. Click on IPVP4 and go to its properties. Switch the toggles from "Obtain automatically" to manual configurations. Use 192.168.10.10 for IP address, 255.255.255.0 for Subnet mask and 127.0.0.1 for Preferred DNS server. I am leaving Default gateway blank for now as currently I am on Isolated VM steup with no internet (I will change in the later labs).

- For Isolated Lab; Go to the VirtualBox VM settings > Network > change "Attached to" to Host-only Adapter or Internal Network

## Step 2: Installation Type and server selection

Here are 2 Options

- Role based or Feature based installation: For now I will go with this type

- Remote Desktop Services Installation

After this list of server with assigned IP will show to select, Click on Next

## Step 3: Selecting roles to install

Here I need to add the required roles to setup in the server

- DNS Server
